📖 WMB Bible d'étude — Élie le Prophète

Version autonome et hors ligne — Bible (66 livres) + 1 213 brochures William Marrion Branham (5 zones, Shekinah + VGR) avec correspondances bibliques, recherche, marquages et notes personnelles.

✅ L'application est prête. Le fichier ZIP (WMB-Bible-Etude-Offline.zip, env. 53 Mo) contient tout le nécessaire : textes bibliques, brochures, images, scripts et Service Worker pour une utilisation 100 % hors connexion.

🚀 Comment l'utiliser hors ligne

Méthode recommandée (meilleure expérience, PWA)

  1. Décompressez le fichier ZIP dans un dossier de votre ordinateur ou téléphone.
  2. Servez le dossier via un serveur web local (obligatoire pour que le Service Worker fonctionne) :
    • Windows : double-cliquez sur demarrer-windows.bat (si fourni) ou ouvrez un terminal dans le dossier et tapez python -m http.server 8080
    • Mac / Linux : ouvrez un terminal dans le dossier et tapez python3 -m http.server 8080
    • Android : utilisez une app comme Simple HTTP Server ou Termux
  3. Ouvrez votre navigateur à l'adresse http://localhost:8080 (ou l'adresse affichée).
  4. Attendez que la page d'accueil charge. Dans le panneau, cliquez sur « Télécharger tous les textes » (installation hors ligne). Quand elle affiche « Tous les textes sont disponibles hors ligne », vous pouvez couper Internet.
  5. Ajoutez à l'écran d'accueil (option « Installer l'application » dans Chrome/Edge/Safari) pour la lancer comme une vraie app.

Méthode simple (sans serveur)

  1. Décompressez le ZIP.
  2. Double-cliquez directement sur index.html. L'application se lance dans le navigateur.
  3. ⚠️ Dans ce mode (protocole file://), le Service Worker n'est pas disponible ; vos notes/marquages sont conservés dans le navigateur mais ne fonctionnent pas entre tous les navigateurs. La lecture et la recherche restent 100 % fonctionnelles.
⚠️ Important : Les données (notes, marquages, préférences) sont stockées dans le localStorage du navigateur. Elles sont liées au dossier/serveur depuis lequel vous lancez l'app. Si vous déplacez le dossier ou changez de port, exportez vos notes via 4 · Paramètres → Exporter toute mon étude avant, puis réimportez-les.
